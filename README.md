# YDM (YgoDuelingMod) II - Mau's Fork
The **Ygo Dueling Mod** for Minecraft aims to reflect the real life TCG experience in a 3D open world game by not only adding the cards but also the packs and their pull ratios to the game.

This fork is mainly intended to improve the mod's experience in my friend group. 

But it is also intended to improve or add features for the ability to implement more cards from different TCG formats, along with trying to improve the experience with new animations and sound.


A wiki page will be uploaded soon to outline some of these new features.

## Fork Plans & Goals
Currently implemented:
- Backport of the Rarity System from YDM 1.19.2
- Slight adjustments to card info display, with symbols for certain stats
- Card Tooltip adjustments to display more info, may improve on in future
- Simple Banlist/Limitation indicators, will be improved in future.

Short-term Plans:
- Sleeves use database (being worked on currently)
- Add animations and sounds in Duel Screen (being worked on currently)
- Open more features up for homebrew/custom cards (being worked on currently)
- Card Crafting and De-Crafting (being worked on currently)
- Items for various card aspects/properties, mostly used for crafting but can be used as a currency of sorts for rp purposes (being worked on currently)
- Make the Deckbox UI scrollable, so that it isn't so crammed for the larger deck size
- Overhauling various graphics, such as sleeves to look more in-line with minecraft

Long-term Goals:
- Fix various duplication bugs (Card Binders, Set Contents, etc)
- Fix card deletion issues with Infinite Card Binders (Full inventory, placing cards while it is loading)
- Make the database use artworks instead of full cards, so that the mod handles card frames and can have different configurable layouts
- Improve Banlist/Limitation functionality
- Card info display overhaul, scrolling and configurable font size. Maybe it would be cool if it has a UI that looks like a card frame?
- Inspect UI that shows card info, while still retaining the zoomed in card
- A item/mechanic that allows players to change a card's rarity/foil
- A item/mechanic that allows players to exchange a set + a rarity foil item for a card in the same set with the same rarity
- 3D Deckbox models, placeable like Shulker Boxes. Seperate models for when a Deckbox is opened in hand, or in world, and if it contains any cards.
- In-world projection of Duels
- A block that displays current duels, so that players don't have to huddle around each other.
- Command-based duel request/invite
- Overhaul of the duel animation system
- Card pack open animations
- Different Duel Field types/layouts
- Playmats and possibly other accessories
- Token Card improvements
- Dynamic Duel Music that checks card stats and player life
- In-Duel display of important card stats such as level and combat stats
- Ability to change a card's combat stats in duel to show buffs/debuffs
- Activate Effect action with announcement showing the card's name
- Logging more Duel actions
- Making the Duel Chat functional
- 1.20+ port
- 1.12.2 backport, don't hold your breath
